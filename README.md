# flashtown.space

The FlashTown website — a futuristic farm and animal sanctuary prototype on
Hawaiʻi Island. A giant interactive business card: 8 pages (Home, Ocean,
Volcano, Lava Tubes, Chickens, Cats, Dogs, Regenerative Practices) built from
real farm photos and video.

Static site. Open `index.html` or deploy the whole directory to Vercel.
